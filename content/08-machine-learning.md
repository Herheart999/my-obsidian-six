# Machine Learning คืออะไร

Source: https://www.aware.co.th/th/machine-learning-%E0%B8%84%E0%B8%B7%E0%B8%AD%E0%B8%AD%E0%B8%B0%E0%B9%84%E0%B8%A3/
Accessed: 2026-05-09

## สรุปย่อ

บทความนี้อธิบายว่า Machine Learning เป็นส่วนสำคัญที่ทำหน้าที่เสมือน "สมอง" ของ AI โดยระบบไม่ได้ถูกกำหนดคำตอบทั้งหมดด้วยมนุษย์ล่วงหน้า แต่ถูกออกแบบให้เรียนรู้จากข้อมูล แล้วสร้างแบบจำลองเพื่อนำไปใช้ตัดสินใจหรือสร้างผลลัพธ์

## ความสัมพันธ์ระหว่าง AI และ Machine Learning

- AI เป็นกรอบกว้างของระบบที่แสดงความฉลาด
- Machine Learning คือกลไกการเรียนรู้ที่ช่วยให้ AI ฉลาดขึ้นจากข้อมูล
- มนุษย์ออกแบบกระบวนการและอัลกอริทึม แต่ตัวระบบเรียนรู้รูปแบบจากข้อมูลเอง
- Deep Learning ถูกยกเป็นหนึ่งในอัลกอริทึมที่ได้รับความนิยมสูงและประยุกต์ใช้ได้กว้าง

## มุมมองจากบทความ

- Machine Learning รับข้อมูลหรือสิ่งกระตุ้นเข้าไป
- ระบบเรียนรู้และเก็บรูปแบบไว้
- ผลลัพธ์ที่ได้อาจอยู่ในรูปตัวเลข โค้ด หรือคำตอบที่ส่งต่อไปให้ระบบอื่นแสดงผล
- ในการใช้งานจริง Data Scientist ต้องทดลองหลายอัลกอริทึมและเปรียบเทียบเพื่อหาโมเดลที่เหมาะสมที่สุด

## ตัวอย่างในชีวิตประจำวัน

- Siri และงานรู้จำเสียง / ถอดความ
- Natural Language Processing
- Face ID
- Google Assistant
- ระบบแนะนำวิดีโอของ YouTube
- ระบบแนะนำคอนเทนต์ของ Netflix

## ตัวอย่างที่บทความเล่าถึง Baidu

- Search engine ที่ใช้การจดจำใบหน้า เสียง และภาษาธรรมชาติ
- การทำงานแบบ open source และเผยแพร่งานวิจัย
- การใช้ ML ร่วมกับ AR
- ระบบช่วยด้านสุขภาพ
- อุปกรณ์ smart home
- รถยนต์ไร้คนขับ
