# DevOps Quick Reference

Source: https://aws.amazon.com/th/devops/what-is-devops/
Accessed: 2026-05-09

## สรุปย่อ

โน้ตนี้เป็นเวอร์ชันย่อของแนวคิด DevOps จากหน้าอธิบายของ AWS เพื่อใช้ทบทวนเร็ว

## นิยามสั้น

DevOps คือการรวมวัฒนธรรม การปฏิบัติ และเครื่องมือ เพื่อให้ทีมส่งมอบซอฟต์แวร์ได้เร็วขึ้น เสถียรขึ้น และปลอดภัยขึ้น

## เป้าหมายหลัก

- เร่งความเร็วในการพัฒนา
- ปล่อยฟีเจอร์ได้ถี่ขึ้น
- ลดความเสี่ยงจากการ deploy
- ทำงานร่วมกันระหว่าง dev, ops, QA และ security ได้ดีขึ้น

## เสาหลักที่หน้า AWS เน้น

- Speed
- Rapid delivery
- Stability
- Scale
- Collaboration
- Security

## แนวปฏิบัติที่ควรจำ

- Continuous Integration
- Continuous Delivery / Continuous Deployment
- Microservices
- Infrastructure as Code
- Monitoring and logging
- Policy as Code

## มุมมองสำคัญ

DevOps เป็นมากกว่าเครื่องมือ มันคือรูปแบบการทำงานที่เน้น shared ownership, automation และ feedback loop ที่สั้นลง
